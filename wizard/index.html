WELCOME

欢迎使用 PRTS 整合包

PRTS —— DeepSeek Harness (dsh) 的一键整合包。
装好 dsh 与所选插件后，安装器会自动打包为桌面 GUI（Electron 窗口包住官方 dsh web，不是浏览器环境）：

· dsh 本体（已安装则直接跳过）
· 插件选择（与界面零冲突，默认全选；已安装的会自动置灰，不会重复安装）
· 自动打包桌面 GUI + 名为 PRTS 的快捷方式，安装完成自动启动

COMPONENTS

选择要安装的组件

插件会安装到官方 dsh web 的 web profile，打开 GUI 即可使用；已安装的自动置灰。
