项目概述：PRTS — DeepSeek Harness（dsh）高效 AI 交互图形化外壳
================================================================

一、项目基本信息
--------------------------------------------------
- 项目名称：PRTS（dsh 的 GUI 整合包 / DeepSeek Harness 图形化外壳）
- 项目代号 / 仓库名：dsh-prts-ui
- 当前版本：v1.0.0（stable 通道 0.9.9 系列）
- 项目官网：https://prts.misser.top
- 所属领域：人工智能+（AI 应用 / 智能交互界面 / 大模型工具链）
- 参赛建议赛道与组别：
  中国国际大学生创新大赛（2026）

  → 按「人工智能 +」分类申报（适配大一无成熟运营、具备创新创意构思的团队）
- 开源协议：MIT

二、项目定位与要解决的问题
--------------------------------------------------
大模型（DeepSeek 等）能力强大，但其官方命令行 / 底层工具（DeepSeek Harness，dsh）
面向开发者和有一定技术门槛的用户，交互以命令行、原生网页为主，上手难度高、体验
不友好。普通用户、非技术背景学生很难直接使用，导致大模型能力无法被广泛、便捷地
调用。

PRTS 正是一个「AI 交互图形化外壳」项目：
- 它不是重复造轮子，而是复用 dsh 稳定的 /api RPC + WebSocket 协议，
  镜像 dsh 的真实状态（工作区、会话、模型、凭证、工具、插件均来自 dsh）；
- PRTS 只提供「外观 + 操作面板」，让用户在友好、美观、专业的图形界面里
  使用完整的大模型智能体能力；
- 因为只依赖 dsh 稳定的 /api 协议，dsh 升级不会导致 PRTS 失效，具备良好兼容性。

三、主要功能亮点
--------------------------------------------------
1. 工作区与会话管理：侧栏列表、新建 / 删除、搜索会话、多选批量归档；
2. 模式 / 模型 / 推理等级 / 权限四级选择：标准、PTC、极简、创造等预设，
   支持厂商-模型两级选择、推理等级（Off/High/Max）、权限预设；
3. 轨迹与日志拆分：按轮 / 步分组的分步时间线（模型、工具事件与耗时），
   可导出 JSON 原始事件日志；
4. 图片附件传递：随消息发送 PNG/JPEG/WebP/GIF，历史图片自动回读；
5. 审批 / 提问弹卡：可批准 / 拒绝 / 回答；
6. 上下文仪表：输入框百分比环保显示上下文窗口占用；
7. 底部实时统计条：轮数、步数、LLM 耗时、工具调用、tokens、缓存命中等；
8. 语音输入：本地 whisper-tiny ONNX 语音转文字，VAD 自动检测，离线可用，
   浏览器原生 speechRecognition 自动优先；
9. 三幕粒子开场动画兼加载动画（PRTS 品牌视觉）；
10. 系统面板（硬件遥测）、设置、插件市场、Git 面板、Skill 坞；
11. 中英文界面、明暗主题；
12. 内置 PRTS 人格（自称 PRTS、称呼用户「博士」）与 PRTS 模式 agent 预设。

四、技术架构与创新点
--------------------------------------------------
- 后端：复用 DeepSeek Harness（dsh）内核，通过 /api RPC + WebSocket（/api/events.mux）
  协议通信，WebSocket 优先、SSE 兜底；
- 前端：带 GUI 皮肤层的 Web 应用（React 等），打包进独立 prts profile；
- 桌面封装：Electron，跨平台；
- 创新点：
  ① 低门槛大模型入口 —— 把复杂的命令行智能体封装成人人可用的图形界面；
  ② 轻量依赖 dsh 稳定协议，跟随 dsh 演进不过时；
  ③ 适配国内网络环境，一键安装、自动镜像回退；
  ④ 视觉品牌化（明日方舟 PRTS 风格）、粒子开场动画、人格化体验；
  ⑤ 支持手机端扫码连接，把桌面变为移动端 App 使用。

五、跨平台与分发
--------------------------------------------------
- Windows：PRTS-Setup-<ver>-windows-x64.exe（自解压一键安装）
- Linux：PRTS-<ver>-linux-x64.run（自解压）
- macOS：PRTS-<ver>-macos.sh
- 手机端：电脑 PRTS → 设置 → 移动端 → 手机扫码连接（同局域网），
  浏览器「添加到主屏幕」即可当 App 用
- 国内网络自动回退 npmmirror，无需访问 GitHub

六、应用价值与前景
--------------------------------------------------
- 面向人群：所有希望便捷使用大模型能力的个人用户、学生、创作者、开发者；
- 场景：日常问答、办公写作、编程助手、学习工具、多智能体协作等；
- 前景：大模型工具链平民化是重要趋势，图形化 + 人格化 + 移动化的
  AI 交互入口具有广泛市场空间。
